# Speedy Eats - Installation & Run Guide

This guide walks you through setting up and running the Speedy Eats project (static frontend + PHP backend + MySQL) locally using XAMPP.

---

## 1. Prerequisites

- Windows (or macOS/Linux with equivalent LAMP/MAMP stack)
- XAMPP (Apache + MySQL) installed
- Browser (Chrome/Firefox/Edge)
- (Optional) Git if you plan to version control

---

## 2. Folder Placement

Place (or clone) the project folder into your XAMPP web root:

```
C:\xampp\htdocs\Food_ordering_web-main
```

Access root URL after setup:

```
http://localhost/Food_ordering_web-main/
```

---

## 3. Database Setup (Two Options)

### Option A: One-Step Automatic Install (Recommended)

Visit in your browser:

```
http://localhost/Food_ordering_web-main/backend/php/install.php?db=speedy_eats&seed=1
```

This will:

1. Create database `speedy_eats` (if missing)
2. Run schema (`schema.sql`)
3. Seed users, categories, and foods
4. Display status messages

After success: DELETE `backend/php/install.php` for safety.

### Option B: Manual Setup

1. Start Apache & MySQL in XAMPP Control Panel
2. Open phpMyAdmin: http://localhost/phpmyadmin/
3. Create database `speedy_eats` (utf8mb4_general_ci)
4. Import `backend/php/schema.sql`
5. (Optional) Run `backend/php/seed.php` for dummy data

## 6. Running the Application

1. Ensure Apache & MySQL are running
2. Go to: `http://localhost/Food_ordering_web-main/index.html`
3. Browse foods, add to cart
4. Login at `/login.html` (use seeded credentials)
5. Access admin panel at `/admin/index.html` (must be admin)
6. Place order at `/order.html` (must be logged in; order empties cart)

---

## 7. Core Backend Endpoints (JSON)

Base path: `backend/php/api/`

- Auth: `auth_register.php`, `auth_login.php`, `auth_logout.php`, `auth_me.php`
- Foods: `foods_list.php`, `foods_show.php?id=`, `foods_search.php?q=`, `foods_by_category.php?category_id=`
- Categories: `categories_list.php`
- Cart: `cart_add.php`, `cart_list.php`, `cart_update.php`, `cart_remove.php`
- Orders: `order_checkout.php`
- Admin: CRUD under `admin/` (categories*\* and foods*\*)

All POST endpoints expect JSON body and return JSON; sessions keep auth + cart.

---

## 8. Common Issues & Fixes

| Symptom             | Cause               | Fix                                            |
| ------------------- | ------------------- | ---------------------------------------------- |
| Blank JSON / 500    | DB not created      | Run install or import schema.sql               |
| Cart not persisting | Cookies blocked     | Enable cookies / same-origin access            |
| Admin link missing  | is_admin=0          | Promote user in DB                             |
| Images broken       | Wrong relative path | Ensure images in `img/food/` / `img/category/` |
| Logout not working  | Cached JS           | Hard refresh (Ctrl+F5)                         |

Check Apache error log: `xampp/apache/logs/error.log` for backend errors.

---

## 9. Updating Configuration

Edit DB credentials in:

```
backend/php/config/database.php
```

Adjust `$host`, `$db_name`, `$username`, `$password` if not default.

---

## 10. Security Notes (Production Hardening)

- Add CSRF tokens for POSTs
- Enforce stricter validation & sanitization
- Rate limit auth endpoints
- Use environment variables for DB creds (e.g., `.env` + loader) instead of hardcoding
- Remove `install.php` & `seed.php` after provisioning

---

## 11. Reset / Re-Seed

To wipe data (dev only):

```sql
SET FOREIGN_KEY_CHECKS=0;
TRUNCATE order_items;
TRUNCATE orders;
TRUNCATE foods;
TRUNCATE categories;
TRUNCATE users; -- if you also want to remove users
SET FOREIGN_KEY_CHECKS=1;
```

Then re-run seed:

```
http://localhost/Food_ordering_web-main/backend/php/seed.php
```
